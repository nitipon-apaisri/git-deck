GitDeck

Desktop Git client for people who work across GitHub, GitLab.com and self-hosted GitLab.

Features

  • Commit graph with branch and tag badges
  • Projects and Split View
  • Pull requests and CI status, read-only

Install

pnpm install
pnpm dev

Requires Node 22.12 or newer.
