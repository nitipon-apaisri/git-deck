GitDeck

Desktop Git client for people who work across GitHub, GitLab.com and self-hosted GitLab. One window, a readable commit graph, and your repositories grouped into Projects.

Features

  • Commit graph with branch and tag badges
  • Projects and Split View for two repositories at once
  • Pull requests and merge requests, read-only with CI status
  • Integrated terminal, stash, worktrees and interactive rebase

Install

pnpm install
pnpm dev

Requires Node 22.12 or newer. Tokens are stored in your OS keychain.

Supported hosts

HostSign-inStatus
GitHubPersonal access tokenSupported
GitLab.comPersonal access tokenSupported

Known limits

No OAuth login yet, and no in-app review of pull requests. See docs/DECISIONS.md for the reasons.
